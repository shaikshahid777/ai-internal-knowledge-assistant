# Employee FAQ & Leave Process Guide

## 1. Overview

This guide provides answers to common employee questions about the documented leave request process.

## 2. Frequently Asked Questions

### Q1. How many annual leave days are available?

Full-time employees are entitled to **24 days of annual leave per calendar year**.

### Q2. How early should I submit planned annual leave?

Planned annual leave should be submitted at least **5 working days before** the requested start date.

### Q3. What information must be included in a leave request?

A leave request should include:

- Employee name
- Type of leave
- Start date
- End date
- Number of leave days
- Reason for leave

### Q4. Is submitting a leave request the same as getting approval?

No. A submitted request is not automatically approved. The request must be reviewed and approved through the designated company process.

### Q5. What if I have an emergency and cannot provide advance notice?

The employee should notify their manager as soon as reasonably possible and submit the required leave request afterward.

## 3. Leave Request Process

The documented process is:

1. Determine the type and dates of leave.
2. Prepare the required leave information.
3. Submit the request through the designated leave request process.
4. Wait for the request to be reviewed and approved.
5. Check the request status through the designated process.

## 4. Cancelling Approved Leave

Employees who need to cancel approved leave should inform their manager and update or cancel the request through the designated leave process.

## 5. Topics Not Covered in This Guide

This guide does not provide information about:

- Sick leave entitlement
- Parental leave entitlement
- Carry-forward limits
- Leave encashment
- Public holiday rules
- Specific approval timelines after submission

For these topics, the Internal Knowledge Assistant should not make assumptions or provide information from outside sources.
